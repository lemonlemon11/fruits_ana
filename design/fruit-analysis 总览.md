# fruit-analysis 总览

🔗 GitHub：https://github.com/leunglegend/fruit-analysis · 相关：[[vibecoding 项目开发]]

## 项目目标
- **最终目标**：拥有一套数据分析平台，手工上传成本数据后能快速得到预计利润，辅助后续定价与进货/销售决策。
- **商业模式**（用户 2026-09-08 原话重述）：果民采购 -> 工厂加工 -> 进出口报关 -> 国内分销；果民采购价即成本价，利润 = 国内销售价格 -（国外成本 + 国内物流报关费用）。
- **第一期目标**：暂不做利润测算（目前没有成本数据），先对存量国内销售数据做存档与可视化报表。

## 技术栈 / 运行形态（第一期）
- 第一期采用「数据模型 + 报表原型」形态，暂不写正式系统。
- 数据录入：上传 Excel/CSV 整批导入。
- 已产出：结算单解析脚本 + CSV 统一数据模型 + 4 张报表原型 PNG + 1 份 ABC 独立分析 Excel。
