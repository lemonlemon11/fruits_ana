## 二、各角色发言摘要

**品牌视觉设计师**（三个方向：三柱升级 / 榴莲盾徽 / 顺仔极简脸）
- 推荐「三柱升级」：承接现有 favicon、A/B/C 与上涨双语义、几何扁平延展成本最低；
- 提醒：顺仔原稿渐变 + 24 刺，16px 会糊，进 logo 必须减元素；
- 榴莲盾徽 16px 下锯齿易糊，需减刺到 8~12 根。

**产品经理**（定位：卖得好、不吃亏，而非"数据工具"）
- 核心信息优先级：**生意信任感 > 丰收上涨 > A/B/C 分级 > 专业工具感 > 数据分析 > 榴莲属性**；
- **SLD 不进主 logo**（40-60 岁用户不认字母缩写），主 logo = 图形符号 + 中文字标「水果市场销售分析」；
- 口号三选一：分好级，卖好价 / 一柜一账，卖得明白 / 看懂行情，多卖钱；
- 顺仔与正式 logo 是**主从关系**：正式场景只用 logo，顺仔做登录页、社群、周边。

**用户代表（果农）**
- 绿 = 好货 A 果，黄 = 熟透快出手，红 = 红火赚钱；转发要"有面子"——带榴莲、带顺仔才肯转；
- **图表感太强的 logo 像写字楼软件广告，不愿转发**；SLD 字母"没人认得齐，别整洋玩意"；
- 忌讳：大片白、大片黑、裂果烂果；榴莲 = 「流连忘返」，好彩头。

**前端工程师**（落地清单）
- 交付物：64 viewBox 源 SVG（favicon / BrandMark 同规格）、16px 可辨版、深底反白版、单色版（水印）、横版 lockup；
- 中文艺术字**必须转曲线**（系统字体跨端必跑版）；16px 下细线 / 渐变 / 滤镜全糊，只留粗轮廓；
- 落地点：替换 `public/favicon.svg` → 重写 `BrandMark.vue` path（solid/inverse 同步）→ 登录页 `--portal-hero-image` 视方案调整；
- 新品牌色入 `styles.css` 令牌，勿散落硬编码。

## 三、争议焦点

1. **专业数据感 vs 用户情感认同**：设计师 / 产品经理倾向三色柱延续，用户代表明确只要榴莲 → 方案二、三即为融合解；
2. **SLD 字母标**：被产品经理与用户代表双重否决，未进入方案（仅保留在英文物料 / 水印场景）；
3. **顺仔能否当主标**：用户最爱，但产品经理认定卡通门面削弱信任感 → 降级为营销资产（方案四）。

## 四、方案对比

| 维度 | 一 · 三色果柱 | 二 · 榴莲果仓 | 三 · 榴莲切面占比环 | 四 · 顺仔徽章 |
| --- | --- | --- | --- | --- |
| 定位 | 专业延续 | 品类折中 | 概念合一（推荐主标） | 亲和营销 |
| 榴莲识别 | 无 | 强 | 强（切面） | 强 |
| 分级/分析语义 | 强（三柱） | 中（窗口内三柱） | 强（占比环即业务） | 弱（小箭头） |
| 16px 可辨 | 优 | 中（退化为绿刺球） | 良（环+三色可辨） | 良（黄脸绿底） |
| 与现有资产延续 | 完全延续 | 部分延续 | 重塑（色系延续） | 延续（顺仔） |
| 商标显著性 | 一般 | 良 | 优 | 良（需与主标分开注册） |
| 用户转发意愿 | 低 | 中 | 中高 | 高 |
| 落地成本 | 最低 | 中 | 中 | 低（限营销场景） |

## 五、主持人裁定建议

- **主标：方案三「榴莲切面占比环」**——唯一把品类与分析合一的方案，兼顾农户（榴莲）与产品（占比），独特性与商标显著性最佳；
- **favicon / 顶栏小尺寸**：若方案三 16px 实测不理想，降级使用方案一（与现 favicon 无缝衔接）；
- **营销资产：方案四「顺仔徽章」**用于登录页、公众号、社群、周边，与主标构成主从双资产体系（呼应产品经理建议）；
- **口号**：主用「分好级，卖好价」，登录页可用「跟着顺仔看行情」；
- 待用户拍板后进入落地：`BrandMark.vue` 重写 → `favicon.svg` 替换 → 中文转曲线 → 单色 / 反白版 → 登录页 hero 调整。

## 六、遗留与风险

1. 方案三的「切面果核」意象是否触碰用户忌讳（裂果 / 烂果）——纪要中已按"完整切面"处理，建议拿方案二 / 三给 2-3 位真实档口老板再测一轮；
2. 组合标中文字当前为系统字体渲染，**定稿前必须换授权字体并转曲线**；
3. apple-touch-icon 恢复与否需遵循 ADR-052（手机端由独立移动版承担），默认不恢复。

# 第二轮讨论（同日追加）：顺立达 × 榴莲 × 物流

- 触发：用户裁定第一轮四方案全部否决，给出新设计简报——**与公司名称「顺立达」
  （SLD 缩写由来）+ 榴莲 + 物流相结合**。
- 第一轮文件归档于 `design/logo/` 根目录，第二轮产出在 `design/logo/round2/`。

## 命名解读（本轮设计主线）

| 字 | 生意含义 | 图形语言 |
| --- | --- | --- |
| 顺 | 启运顺畅、一路绿灯 | S 形干线、流畅曲线（兼 SHUNLIDA 首字母） |
| 立 | 果立枝头、货立市场 | 挺立的榴莲主体 |
| 达 | 使命必达、送达即达成 | 箭头、定位销、「达」字本体 |

## 四方案（详见 round2/preview.html）

1. **顺达航线**：榴莲启运 → 带中线的高速 S 弯 → 定位销送达。三要素最均衡，推荐主标；
2. **榴莲专送**：快递箱 + 微笑榴莲（顺仔表情延续）+ 此面向上箭头 + 速度线。物流感最直白；
3. **达字果标**：「大」化为枝干 + 挺立榴莲 + 双腿，「辶」化为公路 + 上扬箭头。名称入图最深，
   商标独特性最强，门头/车身大字场景最优；
4. **环形干线**：链路闭环环线 + 环心榴莲 + 出环箭头。徽章形态，头像/车贴/水印最优。

## 主持人建议

- 主标：方案一（顺达航线）；门头与商标注册组合：方案三（达字果标）；
- 徽章辅形（头像/车贴/水印/favicon）：方案四；客户端与营销物料：方案二；
- favicon 简化策略：方案一去中线版 / 方案四环+黄心版，16px 实测后定。
- 落地清单沿用第一轮前端工程师意见（BrandMark.vue solid/inverse、favicon.svg 替换、
  中文授权字体转曲线、单色/反白版）。

# 第三轮讨论（同日追加）：数据看板思维 × 视觉伴侣

- 触发：用户否决第二轮（「这个布局还要改，重新讨论」），给出新方向——
  **「向数据看板的思维去，要突出重点的数据，logo 用视觉伴侣呈现」**。
- 第二轮归档于 `design/logo/round2/`，第三轮产出在 `design/logo/round3/`。

## 设计体系：重点数据主角 + 视觉伴侣

| 层级 | 角色 | 承载元素 |
| --- | --- | --- |
| 主角（最大视觉权重） | 重点数据 | 上涨大箭头 / 高亮数据点 / 仪表指针 / ¥ 金额 |
| 伴侣一 | 榴莲（数据源头） | 折线起点 / 卡角徽章 / 仪表轴心 |
| 伴侣二 | 物流（数据终点） | 定位销 / 在途虚线+箭头 |
| 伴侣三 | 名称与等级色 | 顺立达/SHUNLIDA 字标、A/B/C 红黄绿 |

## 四方案（详见 round3/preview.html）

1. **看板 KPI 卡**：卡片本体即看板（窗口三点 + A/B/C 柱 + 白色上涨大箭头 + 卡底在途线 + 卡角榴莲徽章）；
2. **高光折线**（推荐主标）：榴莲为起点、爬升折线、终点高亮光环红定位销——重点全在唯一高亮的数据点上；
3. **仪表果速**：绿黄红量程 + 指针直插红区 + 榴莲轴心，监测/在途隐喻；
4. **金额飙升**：大号 ¥ + 红色上涨箭头主角，榴莲与在途线为伴侣，对果农沟通成本最低
   （注意货币符号商标注册类别限制）。

## 主持人建议

- 主标：方案二「高光折线」（「突出重点数据」执行最彻底，榴莲/物流/看板三要素完整，透明底通用）；
- 方案一「看板 KPI 卡」用于 App 内看板页头图、空状态插画、引导页——logo 形态即产品形态；
- 方案三/四按场景（车载监测物料 / 面向果农的价签海报）备用；
- favicon 简化策略：方案二去光环网格版（绿球-线-红点）；落地清单沿用第一轮。

# 第四轮讨论（同日追加）：专业质感系列（去卡通 / 去塑料）

- 触发：用户批评「怎么感觉这么卡通、这么塑料，人家苹果的 logo 就很好看，要专业的设计」。
- 诊断：① 卡通来自拟人元素（笑脸/眼睛）与外扎尖刺；② 塑料来自高饱和红黄绿并列；
  ③ 元素堆叠（卡+柱+箭+果+线）稀释了主体。
- 处方：删除拟人与外刺，榴莲只留抽象剪影/内在结构；配色改为**深绿色阶
  （#0E4A30/#125033/#17663F/#1F6B45/#2E7D54）+ 米白 #F2EDE3 + 一处香槟金 #C9A06A**
  （金色只授予「重点数据/达成」这一个元素，延续看板思维的 KPI 高亮语义）；
  每方案一个主体 + 一次点睛，全部可单色。等级三色退出 logo，保留在系统图表。

## 四方案（`design/logo/round4/`，详见其 preview.html）

1. **墨绿果钻**：正圆 + 四个弦切面（同系四阶绿，米白细线分光）+ 金色果柄绿叶。高端礼盒线；
2. **负形锯冠**（**推荐主标**）：深墨绿圆角块 + 米白榴莲负形剪影，冠部上升锯齿=尖刺=折线图=
   路径，锯齿尽头一枚金色箭头脱果而出（重点数据点/使命达成）。最贴近苹果式语法；
3. **果径环**：细环断口 + 金色箭头 + 环心果核杏仁（中缝米白细线）。元素最少，单据/水印线；
4. **三瓣果徽**：细环内三枚果肉瓣（=A/B/C=顺·立·达），正北瓣尖一点金色三角。徽章线。

## 主持人建议

- 主标：方案二「负形锯冠」（App 图标 / favicon / 顶栏零改造，含义密度最高）；
- 品牌族共存：果钻（礼盒）、果径环（单据水印）、三瓣果徽（头像/车贴）与主标同色系，
  可作为分场景辅形；定稿时锯齿比例按黄金分割微调、字标换授权字体转曲线。
