（草案）

文档版本：V0.1  |  编制日期：2026-09-21  |  状态：待费用明细补充后定稿

本报价单为商务沟通草案，金额与规格均需双方确认；正式签署前不作为结算承诺。

# 1. 报价说明

- 项目：SLD-水果市场销售分析系统。
- 用途：为果农提供「录单/导入 → 看板 → 单柜诊断 → 货柜/品牌对比 → 导出与顺仔问答」的销售分析工具。
- 报价范围：软件开发与实施、服务器及云资源、域名全打通、微信生态账号开通、持续需求沟通与功能演示确认。
- 工作量依据：`docs/2026-09-21-系统迭代过程与功能工作量清单.md` 及仓库 Git 提交历史、测试与交付记录。
- 计价方式：软件开发与实施按人日计价；云资源、域名、微信生态费用按外购实际成本列支。

# 2. 报价范围与服务边界

已交付能力：

- 文件导入与二次确认、手工录单、导入记录与问题处理。
- 销售总览、数据明细、结算单详情、结算单对比、品牌对比、等级与规格细分。
- 顺仔自然语言数据问答与多页面 AI 分析。
- 登录注册、忘记密码、角色权限、菜单控制、站内通知。
- CSV / XLSX / PDF 导出、来源追溯。
- 桌面端与手机端响应式适配、生产部署与运维加固。

不在本报价范围，需另行确认：

- 利润测算、销售地区维度等第二期能力。
- 大量历史数据清洗、外部系统对接、定制品牌设计等新增需求。
- 客户自有服务器或机房环境改造。
