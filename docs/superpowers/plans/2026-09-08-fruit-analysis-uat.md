# 水果等级销售经营分析平台 UAT

日期：2026-09-08  
状态：执行中

## 验收环境

- 后端：FastAPI + SQLite，本地数据库位于 `backend/data/`。
- 前端：Vue 3 + Vite。
- 真实附件仅用于本地验证，不进入 Git。

## 数据导入

- [ ] 三份结算单都能识别柜号和销售明细。
- [ ] 销售日期为空的后续行继承同一销售段日期。
- [ ] A/B/C 正确标准化，BC 全部计入 C 且保留原始文本。
- [ ] 售后、费用、清关和合计行不误写为销售明细。
- [ ] 金额与数量乘单价误差超过 0.01 时产生警告。
- [ ] 缺少关键字段或未知等级时隔离错误行，有效行继续导入。
- [ ] 同一文件重复上传不新增批次和销售事实。
- [ ] 导入问题可在页面查看并下载 UTF-8 CSV。

## 分析口径

- [ ] 空数据库稳定返回 A/B/C 三个等级和空均价。
- [ ] 销量、销售额、加权均价、数量占比与独立计算一致。
- [ ] 日期与柜号筛选同时作用于指标分子和占比分母。
- [ ] 全局汇总、日趋势、货柜对比和单柜明细口径一致。
- [ ] 单柜销售周期按销售日期最小值和最大值展示。
- [ ] 数据质量异常能按类型统计并追溯到批次/源文件。

## 管理者界面

- [ ] 全局汇总与单柜诊断可按场景切换。
- [ ] 日常跟踪与销售复盘入口明确，筛选状态可理解。
- [ ] A/B/C 指标可直接比较，C 显示“C 果（含 BC）”。
- [ ] 加载、空数据、接口失败和上传中状态均有反馈。
- [ ] 375px、桌面宽屏下无横向溢出、文字遮挡和控件重叠。
- [ ] 键盘焦点可见，表单有标签，交互目标尺寸不小于 44px。

## 导出与追溯

- [ ] 全局 CSV 与相同筛选条件下的 API 汇总一致。
- [ ] 单柜 XLSX 可打开，包含汇总、趋势和明细来源 ID。
- [ ] 导出内容注明筛选范围、生成时间和 BC 归入 C 的规则。
- [ ] 每条标准化销售明细可追溯到导入批次和源文件。

## 自动化验证记录

待全部功能整合后记录实际命令、通过数量与浏览器截图路径。
