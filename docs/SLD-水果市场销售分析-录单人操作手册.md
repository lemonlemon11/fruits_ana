# 1. 手册说明

- 适合谁看：负责接收市场结算单、把数据录入系统的财务人员。
- 讲什么：从拿到一张结算单文件，到数据正式进入系统的每一步操作，以及出错时怎么办。
- 怎么用：第一次使用请从头读到第 6 章；日常操作中遇到问题时，直接查第 11 章和附录 A。
- 本手册描述当前系统版本；界面如有调整，以最新版本为准。

# 2. 每日工作流程总览

每收到一批结算单，建议按以下固定流程操作：

1. 检查文件：确认是 XLSX 文件、按模板填写、商号齐全（见第 4 章）。
2. 登录系统，进入「录单 / 导入」。
3. 上传文件，系统自动解析并进入「二次确认」页。
4. 在二次确认页逐张核对、修正问题行，确认无误后提交（见第 6 章）。
5. 回到「录单 / 导入」下方查看导入记录，确认没有失败或未处理的警告（见第 8 章）。
6. 到「每一单」抽查明细，确认数据正确（见第 10 章）。
7. 没有电子文件的结算单，用「手工录单」录入（见第 9 章）。

# 3. 登录系统

1. 打开系统地址，进入登录页。
2. 输入用户名或邮箱、密码，点击「登录经营台」。
3. 如希望 30 天内免登录，勾选「30 天内免登录」；不勾选默认保持 7 天。

忘记密码时：点击「忘记密码？」，输入注册邮箱收到的 6 位验证码，设置新密码即可。

注意：登录后能看到哪些菜单由管理员分配。如果看不到「录单 / 导入」等菜单，
或登录后只显示「欢迎访问」页，请联系管理员开通权限，不要自行重复注册账号。

# 4. 录单前的准备

## 4.1 文件要求

| 检查项 | 要求 |
| --- | --- |
| 文件格式 | 仅支持 XLSX（Excel 2007 及以上）。XLS 老格式请先另存为 XLSX。 |
| 单文件大小 | 不超过 20 MiB。 |
| 填写内容 | 按结算单模板填写：商号、销售日期、品种、等级、数量、单价等。 |
| 商号 | 每张结算单必须有商号；同一商号在系统里代表同一张结算单。 |
| 一个文件一张单 | 建议一个文件只放一张结算单；多个文件可以一次多选上传。 |

## 4.2 等级怎么填

- 等级写原始叫法即可，如 A、AB、B、BC、C。
- 系统按管理员配置的转换规则归入统计等级，默认口径：**BC 归入 C**，
  界面上显示为「C 果（含 BC）」。
- 空白或无法识别的等级会按「其他」统计，会直接影响 A/B/C 报表准确性，
  所以正常销售行不要留空等级。

## 4.3 容易踩坑的三个写法

| 项目 | 正确写法 | 错误写法 | 原因 |
| --- | --- | --- | --- |
| 规格（头数） | `3/4` 或 `10` | —— | 头数允许区间，也可写单个数字。 |
| 规格（KG） | `10` | `9/10` | KG 只能填单个数字，区间写法会被拒绝。 |
| 数量（件） | `25` | 空着、`0` | 数量必填且必须大于 0，系统不会自动补 0。 |

# 5. 上传结算单文件

1. 在左侧导航点击「录单 / 导入」。
2. 把 XLSX 文件拖入上传区域，或点击区域选择文件。
3. 可以一次多选几个文件；下方队列会显示「已选 N 个文件」及总大小，可在此移除误选的文件。
4. 确认无误后点击「开始导入」。
5. 系统解析完成后自动打开「二次确认」页，等待你核对（见第 6 章）。

- 手机端上传区可以整块点选，同样支持多文件队列。
- 如果解析失败，先检查文件是否为 XLSX、是否按模板填写，修改后重新上传。

# 6. 二次确认（重点）

二次确认是数据进入系统前的最后一道关。**系统只允许没有错误的单通过**，
所以请把这一章读熟。

## 6.1 页面结构

- 多个文件会逐个列出，每个文件分四个分区：
  **基础信息、销售明细、售后明细、费用明细**。
- 单元格内容可以直接点击修改，改完系统会重新校验。
- 页面会把文件里的合计与系统计算的合计（如售后合计、费用合计）并排显示，
  两边对不上的项目会标出差异，方便你发现漏行、错行。

## 6.2 看懂标红

- **整行深红色**：这一行存在错误，必须处理。
- **单元格红色加粗边框**：具体是哪个字段有问题，鼠标看提示或对照弹窗说明。
- **黄色/警告**：属于提醒性质，确认无误后可以放行（见第 8 章）。

## 6.3 销售明细的两种通过规则

每一行销售明细，只有下面两种形态能通过，二选一：

| 形态 | 必填字段 | 必须留空的字段 | 说明 |
| --- | --- | --- | --- |
| 正常单 | 销售日期、品种、等级、头数、KG、数量、单价（7 项全填） | —— | 常规销售行，参与 A/B/C 统计。 |
| 异常单 | 销售日期、品种、备注、数量、单价（5 项） | 等级、头数、KG | 备注型记录，等级自动记为「其他」。 |

判定规则：

- 只要等级、头数、KG 里**任一项**填了内容，就按**正常单**校验，7 项都得齐全。
- 三项全空且备注非空，才按**异常单**校验。
- 不满足任一形态的行会逐字段提示「不能为空」，整行标红，**有错误时提交按钮不可用**，
  不能带错强行提交。

另外两条解析口径：

- **品种**：模板里品种列空着会自动沿用上一行的品种（同一张单内品种通常连续）。
- **等级**：**不会**沿用上一行，每一行都要明确填写等级，空等级行会标红等你在确认页补填。

## 6.4 确认提交

1. 四个分区全部核对完，确认没有红色错误行。
2. 点击「确认提交」。
3. 如果仍有错误或商号冲突，系统会弹出表格列出每一条问题（位置 / 字段 / 问题），
   逐条修正后再提交。
4. 提交成功后，数据正式生成结算单。

# 7. 重复商号与覆盖导入

- 上传的文件商号与系统里已有的结算单相同时，系统提示「已存在待确认」。
- 「覆盖导入」会用新文件**替换**该商号原来的全部数据（销售明细、售后、费用、汇总）。
- 覆盖前请先确认：旧数据确实作废，新文件是正确版本。
- 拿不准时不要点覆盖，先在「每一单」导出旧单留底，或联系管理员确认。

# 8. 导入记录与问题处理

提交完成后，在「录单 / 导入」页面下方「导入记录和问题」查看每批结果：

1. 每条记录显示本批的**成功、警告、失败**数量。
2. 点击「查看问题」展开具体明细，按提示修正。
3. 警告类问题确认没有影响时，可点击「确认无误」放行。
4. 需要留存或转给同事核对时，点击「下载问题明细」导出 CSV。

处理顺序建议：先清失败，再看警告，全部归零后本批才算录完。

# 9. 手工录单

没有电子文件的结算单（如纸质单、微信截图），用手工录单。

## 9.1 开始录单

1. 在「录单 / 导入」页面点击「手工录单」。
2. 如有未完成的草稿，点击「继续录单」接着录。

## 9.2 填写基本信息

商号、柜号、单号、转运公司 / 车牌号、国家（如 越南）、市场、到达市场日期、来货数量（件）。

- **商号必填**，且决定这张单在系统里的唯一身份；修改已有单时商号不可改。
- 「市场」是下拉选择，选项由管理员配置；如果下拉是空的或没有你要的市场，
  联系管理员添加，不要手动把市场名写到其他字段里。

## 9.3 填写销售明细

每行至少填写**销售日期**和**数量（件）**；数量必须大于 0。

- 等级、品种、头数、KG 建议按第 6.3 节「正常单」的标准填全，报表才准。
- 单价可以空着，系统按 0 计算；金额（元）= 数量 × 单价，自动算出。
- 头数可写区间（如 `3/4`）；KG 只能写单个数字（如 `10`），写错会红框提示。

## 9.4 填写售后与费用

- 售后明细：填写内容、摘要、金额（元）。
- 费用明细：按行填写摘要和金额（元）。

## 9.5 暂存与保存

- 点「暂存」可以中途保存；草稿存在系统里，**刷新或换电脑登录后都能恢复**，
  系统也会自动暂存。
- 核对右侧 / 底部汇总无误后点「确认保存」；保存成功后草稿自动清除。
- 商号已存在时系统会要求覆盖确认，规则同第 7 章。
- 手工单保存后可以再次修改，系统会保留修改记录（留痕）。

# 10. 录完后的自查

1. 进入「每一单」，用商号下拉框找到刚录的单（也可搜单号、柜号或车牌）。
2. 点击「查看明细」，只读核对基础信息、销售明细、售后、费用和汇总。
3. 发现录错：小错误在手工录单里改正；整张单报废可点「删除」——
   **删除会把这张单的全部数据和留痕一起移除，不可撤销**，务必先导出留底再删。
4. 需要交给主管或存档时，可导出结算单列表 XLSX，或对单张导出 XLSX / PDF。

# 11. 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 文件上传失败 | 确认是 XLSX 格式、单个文件不超过 20 MiB；老格式 XLS 先另存为 XLSX。 |
| 提交按钮点不了 | 说明还有红色错误行；按 6.2 节找到标红行，补全字段后按钮自动恢复。 |
| 提示「等级不能为空」 | 正常销售行每行都要写等级，等级不会沿用上一行；不想参与等级统计的备注行请走「异常单」写法（等级、头数、KG 全留空 + 备注必填）。 |
| 提示 KG 不能是区间 | KG 只能填单个数字（如 `10`），不能写 `9/10`。 |
| 提示数量无效 | 数量必填且必须大于 0；系统不会自动补 0，空着或填 0 都会被拦下。 |
| 同一商号重复导入 | 系统提示「已存在待确认」；确认替换才点覆盖导入，拿不准先导出旧单留底（见第 7 章）。 |
| 找不到「录单 / 导入」菜单 | 账号没有被分配该菜单，请联系管理员开通权限。 |
| 市场下拉没有选项 | 市场由管理员配置，请联系管理员添加后再录。 |
| 草稿不见了 | 先确认登录的是同一个账号；仍找不到时重新录，并把情况反馈给管理员。 |
| 页面数据为空 | 确认已完成导入并提交成功；查导入记录里是否有失败批次。 |
| 手机上能录单吗 | 可以。底部导航进入「录单 / 导入」，上传、二次确认、手工录单都支持，长表格会自动变卡片。 |

# 12. 附录 A：字段填写速查表

## 基本信息

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 商号 | 必填 | 同一商号 = 同一张结算单；修改已有单时不可改。 |
| 柜号 / 单号 / 转运公司（车牌号） | 选填 | 影响基础信息展示与搜索。 |
| 国家 | 选填 | 如「越南」。 |
| 市场 | 建议填 | 下拉选择，选项由管理员配置。 |
| 到达市场日期 | 建议填 | 影响结算单排序。 |
| 来货数量（件） | 选填 | 与销量对比可发现损耗。 |

## 销售明细（每行）

| 字段 | 正常单 | 异常单 | 填写说明 |
| --- | --- | --- | --- |
| 销售日期 | 必填 | 必填 | —— |
| 品种 | 必填 | 必填 | 如「金枕」；模板内空行自动沿用上一行。 |
| 等级 | 必填 | 必须留空 | 写 A、AB、B、BC、C；BC 自动归入 C；每行都要写，不沿用上一行。 |
| 规格（头数） | 必填 | 必须留空 | 单个数字或区间，如 `10`、`3/4`。 |
| 规格（KG） | 必填 | 必须留空 | 只能单个数字，如 `10`。 |
| 备注 | 选填 | 必填 | 异常单的必填项。 |
| 数量（件） | 必填且 > 0 | 必填且 > 0 | 不能空、不能 0，系统不自动补 0。 |
| 单价（元） | 必填 | 必填 | 手工录单可空（按 0 计）；导入按模板填写。 |
| 金额（元） | 自动计算 | 自动计算 | = 数量 × 单价。 |

## 售后明细 / 费用明细

| 分区 | 字段 |
| --- | --- |
| 售后明细 | 内容、摘要、金额（元）。 |
| 费用明细 | 摘要、金额（元）。 |

# 13. 附录 B：本手册依据的数据口径

| 口径 | 摘要 | 决策记录 |
| --- | --- | --- |
| KG 单数值 | 规格只允许单个数值，区间写法拒绝；头数仍允许区间。 | ADR-043 |
| 数量必填 | 销售数量必填且不得自动补 0。 | ADR-044 |
| 等级不继承 | 等级列不向上继承，正常销售行等级必填。 | ADR-045 |
| 两种通过规则 | 销售明细按正常单 / 异常单两种形态校验，错误行禁止带错提交。 | ADR-046 |

口径如有调整，以 `docs/DECISIONS.md` 最新记录为准，本手册会同步更新。
