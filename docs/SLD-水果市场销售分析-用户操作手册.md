# 1. 手册说明

本手册用于指导使用者完成登录、导入或手工录入数据、查看销售情况、进行对比分析和导出报表等日常操作。

- 如果只是想快速了解页面入口，请先阅读「快速开始」。
- 如果遇到报错或不确定某个指标，请查看「常见问题」。
- 本手册描述的是当前系统版本；界面新增或调整后，请以最新版本为准。

# 2. 快速开始

建议按以下顺序使用系统：

1. 打开系统地址，注册或登录账号。
2. 进入「录单 / 导入」，上传 XLSX 结算单文件，或进入「手工录单」手动录入。
3. 打开「卖得怎么样」，查看总销量、销售额和 A/B/C 等级情况。
4. 进入「每一单」，查看每张结算单和销售明细。
5. 需要横向比较时，打开「结算单对比」或「品牌对比」。
6. 需要留存报表时，在对应页面使用导出功能。

# 3. 注册与登录

## 3.1 创建账号

1. 打开系统地址，进入登录页。
2. 点击「创建账号」。
3. 输入用户名和密码；密码至少 8 位。
4. 再次输入密码确认。
5. 输入用于接收验证码的邮箱，点击「发送验证码」。
6. 输入邮箱收到的 6 位验证码，点击「创建账号」。
7. 成功后自动进入系统。

## 3.2 登录

1. 输入用户名或邮箱。
2. 输入密码。
3. 如希望 30 天内免登录，勾选「30 天内免登录」。
4. 点击「登录经营台」。

- 不勾选免登录时，登录状态默认保持 7 天。
- 登录失败请检查用户名/邮箱和密码是否正确。

## 3.3 忘记密码

1. 在登录页点击「忘记密码？」。
2. 输入注册时使用的邮箱，点击「发送验证码」。
3. 输入邮箱收到的 6 位验证码，点击「验证」。
4. 设置新密码并再次确认，点击「重置密码」。
5. 重置成功后返回登录页。

## 3.4 退出登录

1. 在页面右上角点击用户名旁的退出按钮。
2. 系统会退出当前账号，并回到登录页。

# 4. 认识工作台

登录后进入工作台，主要分为顶部、左侧导航和页面内容区。

## 4.1 顶部区域

- 品牌图标：点击可回到「销售总览」。
- 当前页面名称：显示现在所在的页面。
- 本地时间：显示当前日期、星期和时分秒；手机端只显示时分秒。
- 用户名和退出：显示当前登录账号，可退出。
- 通知铃铛：显示未读数量，可打开通知列表。

## 4.2 左侧导航

主要入口：

- 卖得怎么样：查看销售总览。
- 每一单：查看数据明细。
- 录单 / 导入：上传 XLSX 文件，并进入手工录单。

更多功能：

- 结算单详情、结算单对比、品牌对比。

## 4.3 页签与快捷操作

- 打开过的页面会显示为页签，可快速切换。
- 首页「卖得怎么样」固定保留，其他页签可以关闭。
- 右键页签可刷新当前、关闭当前、关闭其他或关闭全部。
- 页面滚动较长后，右下角会出现「回顶部」按钮。
- 顶部可调整字号，系统会记住最近一次设置。

## 4.4 查看通知

1. 点击顶部铃铛图标。
2. 查看未读数量和通知列表。
3. 点击某条通知可查看完整内容。
4. 可点击单条已读或全部已读。

# 5. 录单与导入

## 5.1 上传文件

1. 在左侧导航点击「录单 / 导入」。
2. 将 XLSX 文件拖入上传区域，或点击选择文件。
3. 确认所选文件后，点击「开始导入」。
4. 系统会解析文件并打开「二次确认」页，等待确认。

## 5.2 二次确认

1. 上传后系统自动进入导入复核页。
2. 逐个文件核对基础信息、销售明细、售后明细和费用明细。
3. 有问题的行会标红，请检查并修改。
4. 确认无误后点击「确认提交」。
5. 若存在错误或商号冲突，系统会再次提示，确认后再提交。
6. 提交成功后正式生成结算单数据。

## 5.3 重复导入处理

- 如果同一商号已经导入过，系统会提示「已存在待确认」。
- 确认需要替换旧数据时，再点击覆盖导入；否则不要点击覆盖。

## 5.4 查看导入结果

1. 提交完成后，在下方「导入记录和问题」查看结果。
2. 每一条记录会显示成功、警告、失败数量。
3. 点击「查看问题」可展开问题明细。
4. 对可确认的警告可标记「确认无误」。
5. 点击「下载问题明细」可导出问题 CSV。

## 5.5 上传前检查

| 检查项 | 要求 |
| --- | --- |
| 文件格式 | 仅支持 XLSX。 |
| 单文件大小 | 不超过 20 MiB。 |
| 必要字段 | 商号、销售日期、等级、数量、单价、金额等按模板填写。 |
| 商号 | 不能缺失，同一商号代表同一张结算单。 |

# 6. 手工录单

1. 在左侧导航点击「录单 / 导入」。
2. 在页面中点击「手工录单」；如有未完成草稿，可点击「继续录单」。
3. 填写基本信息：商号、单号、柜号、转运车号、市场、到达日期、来货数量等。
4. 填写销售明细、售后明细和费用明细。
5. 核对右侧或底部的汇总信息。
6. 可点击「暂存」稍后继续；系统也会自动暂存草稿。
7. 确认无误后点击「确认保存」。
8. 如商号已存在，系统会提示覆盖确认，确认后再保存。

- 刷新页面后未提交的手工草稿会自动恢复。
- 保存成功后草稿会被清除。
- 同一手工单可再次修改，修改会留痕。

# 7. 查看销售总览

1. 在左侧导航点击「卖得怎么样」。
2. 如需筛选，选择「销售日期起」「销售日期止」和商号。
3. 切换商号后会立即刷新；修改销售日期后点击「查看结果」。

- 总销量：所选范围内的总件数。
- 总销售额：所选范围内的总金额。
- 每件均价：销售额 ÷ 销量（件）。
- A/B/C 卡片：查看每个等级的数量、金额、每件均价和占比。
- 等级图表：查看等级件数结构、各等级每件均价和各规格件数/均价。

# 8. 查看每一单

1. 在左侧导航点击「每一单」。
2. 使用商号下拉框选择某一结算单，或保留「全部结算单」。
3. 如需要，可设置销售日期范围后点击「查看结果」。
4. 可输入关键字搜索商号、单号、柜号或车牌。
5. 在列表中查看每张结算单的销售额、A/B/C 件数、每件均价等。
6. 点击某张结算单右侧的「查看明细」，查看每条销售记录。

## 8.1 查看明细

- 「查看明细」以只读方式展示基础信息、销售明细、售后明细、费用明细和汇总信息。
- 只读模式不能编辑或提交，关闭页面即可返回列表。

## 8.2 删除结算单

- 如果结算单录错，可点击「删除」。
- 删除会同时移除该结算单的销售明细、售后、费用、汇总和留痕，请谨慎确认。
- 误删不可在页面撤销，请联系管理员处理。

## 8.3 导出列表或单张

- 可导出当前筛选范围的结算单列表 XLSX。
- 也可对某一行单独导出结算单模板 XLSX 或 PDF。

# 9. 查看结算单详情

1. 在「更多」中进入「结算单详情」。
2. 在商号下拉框选择要查看的结算单。
3. 如需要，可设置销售日期范围后点击「查看结果」。

页面主要展示：

- 基础信息：市场、单号、到达市场日期、销售日期、柜号、转运公司。
- 销量、销售额、每件均价。
- A/B/C 等级销售情况。
- 每日销量与每件均价趋势。
- 售后金额/售后比、市场费用、费用明细、应付金额等。
- 与同品牌其他结算单的对比。
- 销售明细和来源文件追溯。

# 10. 对比结算单

1. 在「更多」中进入「结算单对比」。
2. 设置销售日期起止。
3. 点击「查看结果」。
4. 在结果上方选择排序方式：按销售额、销量或每件均价。

该页面用于快速找出销售额最高、销量最大或每件均价最高的结算单；每张结算单还展示 A/B/C 各等级的等级、每件均价和占比。

# 11. 品牌对比

1. 在「更多」中进入「品牌对比」。
2. 设置销售日期范围，点击「查看结算单」。
3. 点击「选择结算单」，在抽屉中勾选同一品牌下的两张或更多结算单。
4. 点击「确定」，下方立即显示对比结果。

## 11.1 选择器说明

- 先选择品牌，再选择该品牌下的结算单。
- 可以搜索商号、单号或柜号。
- 可以按系列折叠或按最近到达日期排序。
- 已选组合会出现在地址栏，分享链接可以还原相同选择。

## 11.2 查看对比结果

- 结算单总览表：逐张查看件数、金额、每件均价。
- 品牌汇总：同一品牌的多张结算单合并查看。
- A/B/C 独立表：每个等级分别查看。
- 等级价差：查看 A-B、B-C 价差和 B 比 A 折价。
- 图表：查看每件均价和结构对比。

## 11.3 按等级号别查看

1. 在详细分析中点击「按等级号别」。
2. 查看每个号别的价格阶梯和数量。
3. 无法识别的等级写法会归入「其他」。

# 12. 使用 AI 与顺仔

## 12.1 顺仔数据问答

1. 在右下角点击「顺仔」机器人。
2. 在对话框中输入问题，例如「本月哪张结算单卖得最好」。
3. 顺仔会基于系统已有数据回答，并可多轮追问。
4. 系统没有的字段（如采购成本、利润）会直接说明。
5. 无权限的账号不会看到顺仔入口。

## 12.2 在页面生成 AI 分析

- 在结算单详情中，可选择生成单柜经营解读。
- 在品牌对比页面，可以选择让系统生成一段大白话分析。

按系列生成分析：

1. 选择两张至六张同品牌结算单。
2. 在「按系列」视图点击「生成分析」。
3. 等待片刻，系统会展示结论、比较和建议。

按等级号别生成小结：

1. 切换到「按等级号别」视图。
2. 点击「生成号别小结」。
3. 查看号别价格差异和品质标记相关解读。

- 相同条件再次生成时，系统可能直接返回缓存结果。
- 如果 AI 未配置或暂时不可用，不影响其他页面。

# 13. 导出数据

## 13.1 总览 CSV

总览页可导出等级汇总 CSV，包含销量、销售额、每件均价和占比。

## 13.2 结算单列表 XLSX

在「每一单」可导出当前筛选范围的结算单列表 XLSX，包含结算单汇总、销售明细、售后明细、费用明细和说明。

## 13.3 单张结算单 XLSX / PDF

结算单详情或列表可导出单张结算单的 XLSX 或模板版式 PDF，内含说明、等级汇总、每日趋势和销售明细等。

## 13.4 手工单 XLSX

手工录单保存后，可从相关入口导出手工单 XLSX。

## 13.5 导入问题 CSV

数据导入页中，有警告或失败记录的批次可下载问题明细 CSV。

## 13.6 来源追溯

在结算单详情中可查看每条销售记录对应的源文件信息。

# 14. 手机端使用说明

- 手机端使用顶部 header 和底部大按钮导航。
- 底部导航保留三个主要入口；更多功能在底部「更多」面板。
- 长表格会自动改为卡片，减少左右滑动。
- 部分详细分析默认收起，点击「展开详细对比」查看。
- 字号可根据需要在顶部调整，并自动记住偏好。
- 文件上传区域在手机上可整块点选，并显示多文件队列摘要。
- 顺仔对话窗会跟随软键盘调整，避免被遮挡。

# 15. 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 登录失败 | 检查用户名/邮箱和密码是否输入正确；密码区分大小写。 |
| 收不到验证码 | 检查邮箱是否填写正确，并查看垃圾邮箱；60 秒后可重新发送。 |
| 账号被禁用 | 登录时提示「该用户已被禁用」，请联系管理员处理。 |
| 文件上传失败 | 确认文件是 XLSX，且单个文件不超过 20 MiB。 |
| 同一商号重复导入 | 系统会要求确认；如不确定是否覆盖，请先下载原数据或联系管理员。 |
| 页面数据为空 | 确认已经导入数据，并检查销售日期范围是否正确。 |
| 日期筛选无效 | 修改销售日期后需要点击「查看结果」；商号切换通常会自动刷新。 |
| AI 分析失败 | 可能是 AI 服务未配置或网络异常，稍后重试；不影响普通查询。 |
| 看不到顺仔 | 当前账号可能没有 ask:view 权限，请联系管理员授权。 |
| 手机端内容显示不全 | 刷新页面；如仍有问题，请切换为桌面模式或联系管理员。 |
