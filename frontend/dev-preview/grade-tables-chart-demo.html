等级独立对比，用哪种图最直观？

同一份真实数据（品牌「香香」全部结算单，取自「品牌对比」接口 get_series_comparison） 分别用三种图展示，挑一个再落地。

推荐：方案 A · 分面小图（柱 = 件数，折线 = 每件均价）

  • 和现在「每等级一张表」的心智完全一致：一等级一卡，只是把表格换成图，学习成本为零；
  • 柱高看量、折线看价，一张小图同时回答「这个等级卖得多不多、卖得贵不贵」；
  • 所有小图横轴同序，同一张单在不同等级间高低一眼对照；某单缺该等级时折线断开、柱缺失，不造假。

方案 B 适合结算单很多、想一屏看全的时候；方案 C 适合「找异常单」（量小价高 / 量大价低）。 三者不互斥，落地时可只做 A。

方案 A · 分面小图（推荐）

每个等级一张小图：柱 = 件数（左轴），折线 = 每件均价（右轴，元/件）；若某单缺该等级则柱缺失、折线断开

优点：等级独立的心智不变；量价同屏；悬浮提示仍给全量四指标（件数/金额/均价/占比），不丢表格信息。

注意：「统一刻度」下 B 果柱子比 A 果矮是真实差距（件数确实少），切「各自刻度」可看清本等级内的波动。

落地口径：等级顺序与颜色沿用 activeGrades / gradeColors；「其他」兜底等级与「等级均价对比」图一致不展示（见页首数据说明）；原表格折叠进「查看数据表」（同「按等级号别看价格」的做法）。

方案 B · 分组柱状图（备选）

横轴 = 结算单，每个等级一组柱（件数，左轴）+ 一条同色均价折线（右轴，元/件）；占比看悬浮提示

优点：一张图放全等级的量与价，占位小；结算单多时也撑得住。

注意：等级「挤在一起」，独立感弱；等级一多（A/B/AB/C/…）柱和折线都会挤，折线交叉时不如方案 A 清楚。

方案 C · 量价散点图（备选）

横轴 = 件数，纵轴 = 每件均价，气泡大小 = 金额，颜色 = 等级

优点：一图找异常——右上「量多价高」卖得最好，左上「量少价高」可惜了，右下「量多价低」值得排查。

注意：对不熟悉坐标图的读者门槛略高，更像分析视角；建议作为 A 的补充而非替代。
