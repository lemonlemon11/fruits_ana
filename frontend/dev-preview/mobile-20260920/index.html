📱 手机版改版设计稿

针对「手机上显示不清晰、内容太挤」的反馈，重新设计整套手机端版式与交互。截图取自 53000 真实前端（390×844，iPhone 14 视口，2x 像素密度）。第二轮补上了手工录单紧凑化、长表单 / 长文折叠与外壳高度收口，并把导入二次确认页改成整屏。

已落地到 53000 视口 390 × 84412 个页面2026-09-20 ~ 09-21

以下都是整页长图：底部导航已被摆到页面最底部（真实使用中它固定在屏幕上）；「顺仔」入口与「回顶部」是视口锚定的悬浮按钮，长图里已隐藏，避免造成误解。

外壳瘦身

  • 手机端隐藏「已打开页签」栏，省下 58px 垂直空间（底部导航已覆盖同批入口）
  • 页脚留白抬高，同时躲开顺仔入口与「回顶部」按钮，微信公众号不再被压住
  • 顶栏高度 60px → 48px，左右内边距 14px → 10px
  • 底部导航高度 92px → 80px，并把悬浮按钮的落点一起抬高
  • 内容区左右留白统一为 10px，首屏多装约 1 行内容

筛选栏单行化

  • 筛选控件改为单行不换行，超出部分横向滑动，不再折成两三行
  • 控件高度 44px → 38px，标签与取值同行显示
  • 查询按钮固定在行尾，不再独占一整行

表格不再被切

  • 规格表从「6 列横向滚动」改为两行式：首行等级规格+占比，中间进度条，末行件数+均价
  • 消除 520px 最小宽度导致的右侧内容溢出
  • 12 个页面文档宽全部 = 视口宽，无页面级横向溢出（详情页筛选栏为设计内滑动）

卡片重排

  • 结算单列表卡片改为四段式：标题 → 三项指标 → 等级胶囊 → 操作按钮
  • 「查看明细 / Excel / PDF / 删除」从挤压标题改为独立操作行
  • 等级卡片由横向滚动改为纵向堆叠，指标三列对齐

长表单与长文折叠

  • 手工录单五个分区在手机上可点击折叠，默认只展开「基本信息」，其余折成一行 44px
  • 折叠头带小计（行数 / 费用合计 / 应付金额），不展开也能看到关键数
  • AI 结论默认只露开头并做渐隐，点「展开全部结论」再看全文，详情页高度少 1300px
  • 点分区锚点会自动展开对应分区；校验不通过时自动展开全部分区

导入二次确认整屏化

  • 弹窗从「居中卡片 + 24px 外边距」改为整屏，390px 上多出 48px 可用宽度
  • 「已入库 · 只读」原来在头部、文件条、提示条重复三遍，手机端只留底部那一条
  • 弹窗头部收成一行：状态胶囊 + 关闭，不再竖排占两行
  • 明细表按列名排版，多出来的「文件行」在卡片里改成一枚小徽标，不再和金额列撞车
