这一稿的来源

直接沿用 2026-09-22 全站布局重设计（redesign-20260922，业务在 53001/53002 评审过的版本）的版式与视觉， 第三稿只做两件事：① 把该版式完整套到双端九个代表屏；② 为管理端补齐同风格的表格、页签、抽屉与通知组件。 配色回到亮色（燕麦绿画布 + 深绿骨架 + 琥珀主操作），排版骨架与 09-22 完全一致：

· 桌面：深绿渐变侧栏（品牌块 + 三分组导航 + 底部用户）+ 浅色毛玻璃顶栏（页标题 + 日期/商号筛选 chip + 通知 + 用户）；
· 手机：渐变绿 appbar + 底部五格 tabbar，中间格琥珀凸起 FAB（录单主操作）；
· 内容节奏：KPI 卡带 4px 左色条、首卡琥珀 hero 放大 → section-title（标题+more）→ 圆角卡（16px、柔影、浅描边）；
· 列表：桌面表格卡（brand-50 表头）+ 手机单据卡（大金额 + A/B/C 三段占比条）；等级用 grade-tag 徽标与三段迷你条表达。

管理端同风格扩展

· 侧栏沿用深绿渐变与同款导航项（选中态白 13% 底 + 琥珀左指示条）；
· 顶栏去掉筛选 chip，换成日期时钟 + 账号 chip + 退出，下方加下划线页签行；
· 列表工具条（搜索 + 下拉 + 主操作）与表格卡沿用用户端表格样式；
· 新增右侧抽屉示意（虚线框）：表单字段、角色勾选卡、启用开关。

与 09-22 原版的差异

· 原版仅用户端 8 页，本稿补齐管理端 4 屏与登录双端；
· 原版外壳由 redesign.js 注入，本稿为纯静态 markup（评审稿更直读）；
· 组件令牌零改动，落地时两端可直接复用 redesign-20260922/redesign.css。

落地方式

确认后：用户端按 redesign-20260922 的既有计划合入 styles.css 与 AppShell； 管理端把 redesign.css 令牌段与表格/工具条样式合入 fruits_ana_admin 的 styles.css 与 AdminLayout。 等级色、口径文案、接口均不动，只改布局与样式。
