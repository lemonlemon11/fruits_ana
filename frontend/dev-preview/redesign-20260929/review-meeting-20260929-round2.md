### 3.2 议程（8 项）

1. 全站容器语言统一：三种容器收敛为一种区块卡片规范，消除三圈嵌套描边与白盒/灰盒交替——内容、顺序、字段不动。
2. 表格方言合并：spec-table 与 DataTable/ElTable 统一为唯一表格样式规范（表头底色、合计行、外框、数值列对齐当场拍板）。
3. 数字与标题字号标尺：3~4 档数字层级与 h2/h3 规则，先在总览 KPI 条与详情经营指标条验证「锚点数值最醒目」。
4. 筛选条统一版式：四页 filter-bar 统一栅格、控件高度、label 字号、主按钮位置（字段、文案、查询行为不变）。
5. 间距与圆角标尺：少档位间距令牌与两档圆角，替换 6/8/9/10/11/12/14/18/24 混用，补 quality-summary 无圆角、mode-card 顶条独例等漏洞。
6. 外壳密度与激活态统一：不改菜单分组与页签行为前提下评估 chrome 压缩空间；侧栏/页签激活二选一。
7. 状态区与辅助区克制化：骨架轻量化（遵守 prefers-reduced-motion）、AI 卡降权、空态三写法收敛为一套。
8. 总览页首屏栅格试排：区块顺序不变前提下各出一版栅格与密度方案供对照打分。

### 3.3 保留优点（5 条，新方案必须继承）

1. **导航与信息架构清晰稳定**：左侧栏两级分组由管理端菜单树驱动（shellMenu.ts、AppShell.vue:703-719），配页签栏与页头副标题——本轮只动排版样式，骨架原样保留。
2. **设计令牌已收敛**：`--ink/--muted/--line/--surface/--primary` 墨绿系（styles.css:10-29），Element Plus 主题变量完整映射（styles-element.css:7-32），改令牌即全站生效。
3. **数字可读性基建扎实**：tabular-nums 全站贯彻，formatCurrency/Number/Price/Percent 统一口径，锚点数值在 KPI、表格、图表三处一致。
4. **克制的亮色商务基调**：无投影、低饱和，适合长时间盯盘——「业务工具不是海报」，只精修节奏与层级不推翻。
5. **无障碍与降级体系完整**：skip-link、aria、focus-visible、prefers-reduced-motion、四档字号缩放（AppShell.vue:595-621），新排版不得倒退。

## 四、三方两轮意见要点

### 4.1 首轮

#### UI 视觉设计师（发现 10 条）

**方向偏好**：「一层白卡」容器律（页底唯一区块卡＝白底 + 1px line + 统一圆角内距，卡内分层只用分隔线与 surface-soft）；表格退深就浅、深色只给导航与主按钮；数字三级标尺（锚点 ≈1.7rem > 区块 ≈1.2rem > 表格 .95–1rem，Bahnschrift + tabular-nums）；密度向日常工具看齐（chrome ~100px、控件 44/36、间距全 rem）。

- **总览 KPI 三层线框**：两圈描边不承载层级信息纯是噪音 → 确立「页面只允许一层容器描边」，total-strip 去 border 改 1px 底部分隔线（仅总览作用域覆盖，不影响结算详情 settlement-strip），KPI 升锚点字号。
- **市场销售分析容器+标题双轨**：灰盒(#e8eee9)铺在几乎同明度页底(#eef3ef)上边界勉强成立；居中主色长标题三重强调 → 图表盒统一白底卡，长标题降级为 h2 下左对齐 muted 说明行（文案原样保留）。
- **表格双方言**：以 DataTable 浅色方言反向改造 spec-table（表头 surface-soft 底 + ink 字、合计浅底 + 2px 上边框、外框 1px）；全列居中按源码注释用户既有要求保留（SettlementGradeBreakdown.vue:294-295）；分段切换激活态 #1f2923 实底改 var(--primary)。
- **详情页数字层级倒挂**：建三级数字令牌 `--num-hero/--num-block/--num-cell`，metric-strip 升区块档，settlement-fact-grid 维持小字，同一 DOM 只动 CSS。

- **品牌件数汇总行**（settlements.json brand_totals 实测：总 29,771 · 香香 27,760（14 柜）· 晴牌 2,011（1 柜））：判断「哪个品牌走得动」的背景锚点只有 .84rem muted → 整行升 .95-1rem、品牌名 ink、数量 primary-dark + tabular-nums。

### 4.2 二轮交锋（焦点裁决）

#### 交锋一：侧栏/页签激活态——三方三票

- **PM**：主张侧栏与页签统一为同一种实心主色。**UI/UX 双双反驳**：现状病根就是两处绿色激活并列，把页签也改实心只是「两个更响的答案」，会摊薄侧栏主导航地位；且页签横向成排带关闭按钮，实心后像一排主按钮。
- **UI**：页签改直角小芯片（999px 胶囊 → --radius-sm）+ 墨色 700 + 2px 主色下边线，形成「导航=块、页签=线」对比。
- **UX**：保留胶囊外形，激活降为 surface 底 + ink 加粗 + line-strong 描边（去绿底绿字绿描边），「导航定位」与「会话页签」两个概念不应共享同一最强答案。
- **PM 再反驳 UI/UX**：2px 细线或「描边换描边」对不常上网的用户太弱，需要「点开的东西有一块颜色变化」的强反馈；页签浅绿底是线上既有习惯，换成另一种等于让用户再学一次 → 页签保留 primary-soft 浅绿底 + 墨绿粗字，仅去与侧栏竞争的绿描边。
- **裁决**：不强求统一——侧栏实心墨绿为全站唯一强激活是三方共识底线；页签语言成为**三案分化维度**（L 取 PM 浅绿底去描边 / M 取 UX 中性胶囊 / N 取 UI 下边线芯片）。

#### 交锋二：筛选条 label 字号——三方三档

- **PM**：1.05rem 墨色不低于正文（SearchableSelect placeholder 已是灰字，label 变灰后控件上下两行都灰、层级塌掉；两字标签缩小省不出宽度）。
- **UI**：.9rem 灰 600（标签是控件注解不是内容，正文尺寸 + 粗体会把操作带抬成需要阅读的表单）。
- **UX**：折中 .9rem/muted/700 置控件上方，输入值 1rem ink，「值 > 标签 > 无关」三层。
- **裁决**：控件高度可压（3.06→2.59rem）；label 字号成为**三案分化维度**（L .95rem ink 保 PM 墨色立场降半档 / M .9rem muted 600 / N .9rem ink 600）。PM 补充：error-banner「重新查询」按钮需同步跟新控件档，否则改一半多一种高度。

#### 交锋三：圆角档位与单位制

- UI 首轮提卡片 8px，二轮自行撤回：styles-element.css:20 已把 EP `--el-border-radius-base` 绑定 `--radius-sm`(4px)，全库 8px×15 处映射既有 6px 改动最小。
- UX 裁决（重跑 grep 实测 var(--radius-sm)×49、999px×28、8px×15、6px×9）：**三档 4/6/999**——4px 微件（图例点、badge）、6px 一切卡片/表格/输入框/对话框、999px 胶囊；卡片定 6px 零迁移成本；若集体坚持 8px 须连 EP 令牌映射与全部手写值一次替换，禁止 6/8 并存。
- 单位制：PM 反驳 UI 的固定 px 表述——外壳支持四档字号缩放（无障碍能力不得倒退），高度改 px 会在特大档裁字 → **压缩目标一律 rem 落地**（header 3.3rem、页签 2.82rem、控件 2.59rem），px 仅作标准档（1rem=17px）换算说明。
- 间距：UX 反驳「页级一律 16px」硬规则——结算单列表 12px/桌面 6px 是源码注释记录的单屏设计目标（SettlementListView.vue:743-756「把高度让给列表」）→ 令牌 8/12/16/24 允许两档页面密度（展示页 16 / 工作台页 12）。
- 死 CSS 处置：UX grep 验证 `.upload-workbench` 全库 0 模板引用（styles-dashboard.css:44、styles-responsive.css:16,171 等仅 CSS 残留）→ 删除；PM 复核确认并提醒导入页是「怕传错」高焦虑页，mode-card 删 3px 顶条后须保 h2 800 字重让两入口仍可辨。

### 4.3 会议收敛的关键共识

1. **一层白卡容器律**：灰绿页底上唯一区块卡 = 白底 var(--surface) + 1px var(--line) + 统一圆角 + 16px 级内距，卡内禁止第二个带边框容器（total-strip / market-chart / chart-block 全部去内框改排版分隔），区块内容/顺序/字段零改动。
2. **表格唯一浅色方言**：浅绿表头 + 1px 外框 + 「2px 顶线 + 浅底加粗」合计行；表体全站统一 .95rem、表头 ≥.85rem；深墨绿实底从一切数据区退场（含每日折线分段切换同批改），只属于侧栏激活与主按钮；**规格表全列居中保留为源码注释记录在案的用户特例**，对齐口径若再议须记 docs/DECISIONS.md。
3. **数字三级 + 文字五档双标尺**：hero 1.7rem > block 1.2rem > cell .95rem（Bahnschrift + tabular-nums）；正文 1rem／辅助 .9rem／标签 .85rem／微标 .82rem（14px 硬底线），整改全部破线处。
4. **间距令牌全 rem**：`--space-2/3/4/6` = 8/12/16/24，允许「展示页 16 / 工作台页 12」两档受认可的页面密度；移动端 12px 替代 6px。
5. **圆角三档**：4px（微件）/ 6px（一切卡片、表格、输入框、对话框）/ 999px（胶囊）；手写 8-12px 全映射 6px；quality-summary 补圆角；删 upload-workbench 死 CSS。
6. **侧栏实心墨绿 = 全站唯一强激活**；页签语言三案分化（浅绿底去描边 / 中性胶囊 / 下边线芯片）。
7. **密度压缩全 rem 落地**：chrome ≈100-104px（header 3.3rem + 页签 2.82rem）、控件两级 44px(2.59rem)/36px(2.12rem)，特大字号档不裁字。
8. **筛选条唯一栅格**：minmax(240px,1.4fr) + n×minmax(140px,1fr) + auto 主按钮最右；≤860px 两列 / ≤560px 单列 + 按钮通栏；废弃列表页横滑变体；label 字号三案分化（.95 ink / .9 muted / .9 ink）。
9. **状态层克制化**：骨架仿卡占位条 + 低幅 pulse（prefers-reduced-motion 静态 + sr-only）；空态一套 dashed 框；AI 卡去左边条与满铺底降为安静辅助区（左边条语言留给警示）。
10. **图表融入度**：同行画布同高、跨行一档；「图窄表宽」行统一 2fr/3fr + gap 12px；ECharts option 零改动（仅画布高度与色板起序）；市场/品牌色板从 #2f6f8f 起序避开等级绿棕。
11. **标题双档令牌**：h2 ≈1.25rem/800/ink 左对齐（不用主色不加居中）、h3 1rem/700；市场销售分析居中主色长标题降级为左对齐 muted 说明行（文案原样保留）。
12. **动作带与作用域**：查询主按钮唯一在筛选条；区块动作在标题行右侧 secondary 档；跨区块筛选通栏贴标题下、单表筛选收进 block-heading 右侧。
