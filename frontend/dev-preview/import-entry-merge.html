「数据导入 + 手工录单」入口整合

两种录入方式都保留，合并成菜单里的一项。下面三个方案可以点着对比，桌面与手机都能切。

需要一起定的交互点

  • URL 与刷新：切换方式用 ?mode=manual，刷新 / 分享 / 浏览器后退都停在同一个方式上，页签栏也只占一个页签。
  • 未保存内容：手工录单填到一半切去看文件导入，不丢草稿；切换时顶部提示「手工录单有未保存内容」，切回来内容还在。
  • 权限差异：只有 entry:view 的人看得到「手工录单」，其他人进来就是普通的数据导入页，不出现空的切换按钮。
  • 从详情页改单：结算单详情的「修改」入口跳到 /imports?mode=manual&merchant_no=…，老链接 /entry?… 保留 301 到新地址。
  • 导入后的引导：文件导入完成后，结果区给一个「也可以手工补录」的次级入口，避免两套流程各说各话。
  • 移动端：底部导航从「4 项 + 更多」变成「录单 / 导入」占一格，手工录单不再藏在「更多」里。
